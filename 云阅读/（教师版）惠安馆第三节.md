
## 第一部分：内容梳理

### 一、整体概述

第三节承接前文英子与秀贞日益亲近的关系，进一步展开秀贞与思康的爱情往事。本节的叙事节奏较前两节更慢，日常琐事与秀贞的回忆交替展开，呈现出“平静中见悲伤”的氛围。英子在这一节中开始出现恍惚、迷失的状态，她的主观感受与客观现实之间的界限日益模糊，为后续的“认亲”高潮埋下心理伏笔。

### 二、逐段情节梳理

#### 第一层：捉吊死鬼——日常中的不祥（开头部分）

英子拿着空瓶和竹筷子，溜进惠安馆跨院，把槐树上垂下的“吊死鬼”（槐树虫）一条条装进瓶里，准备带回家喂小油鸡。这是一段描写儿童“玩虫”的日常，但“吊死鬼”这个名字、蠕动的形态、装在玻璃瓶中的景象，都带着隐约的不安感。

| 细节 | 说明 |
|------|------|
| 英子每天弄一瓶吊死鬼 | 这已成为她的“日常” |
| “吊死鬼”的名字 | 既是虫名，也是不祥的暗示 |
| 瓶子里的虫子“咕噜咕噜地动” | 英子觉得“肉麻”，但仍坚持捉 |
| 想到妞儿 | 英子一边捉虫一边担心妞儿 |

#### 第二层：妞儿来访——秘密的加重（承上）

妞儿两天后找到英子，脸被打得红肿，哭着说“我要找我亲爹亲妈去”。她告诉英子自己的计划：去齐化门，慢慢找。妞儿把两件衣服藏在西厢房空箱子里，表示“不定哪天就要偷偷地走”，走之前会来告诉英子。

> 这是妞儿身世线索的进一步展开，明确了她“不是亲生的”“住在齐化门”两个关键信息，与秀贞的故事构成直接呼应。

#### 第三层：英子的不适——心理变化的开端

英子听了妞儿的事后，“心里很不舒服”，晚上吃不下饭，躺在床上哭起来。妈妈和宋妈问她，她竟哭着说“妞儿她爸爸啊……”又改口说“我要找我爸爸”。这说明英子已经开始把秀贞、妞儿和“找爸爸/找妈妈”这件事在情感上联结起来。

#### 第四层：跨院日常——秀贞世界的展开

英子再次来到惠安馆跨院，看到秀贞在对着空床说话、伺候“病人”（实际上是她的幻觉）、养蚕、收拾屋子。秀贞的言行继续在“真实”与“幻觉”之间摇摆，但她的举止在英子看来越来越“像真的”。

| 秀贞的行为 | 看似“疯”的层面 | 可以理解的层面 |
|-----------|----------------|----------------|
| 对空床说话，说“让他睡去吧” | 对着空气说话，幻觉中有人 | 她把思康还在身边的幻觉当作真实来维持 |
| 养蚕 | 给小桂子装墨盒用 | 为“小桂子将来上学”做准备 |
| 打扫蚕屎装进铁罐 | 攒“明目的”枕头给思康 | 她一直在为“思康会回来”生活 |

#### 第五层：秀贞的爱情叙事——本节的华彩段落

秀贞向英子详细讲述了她和思康相识、相恋、分离的完整过程。这是本节最重要的文本段落，也是全书情感浓度最高的段落之一。

**秀贞的叙述可分为以下阶段：**

**阶段一：思康初到（客观叙述）**
- 思康搬进跨院，穿灰大褂，大襟上别着一支笔
- 父亲（老王）帮他收拾，铺开“又薄又旧的棉被”
- 秀贞偷偷看他，“两只眼儿到底有多深！你还没看清楚他，他就把你看穿了”

**阶段二：情感的萌发（初识阶段）**
- 秀贞每天给思康送开水，“绷着脸儿”，不看他
- 直到有一天，她“微探着身子看他写什么”，他扭过头来说“认得字吗？”
- “打这儿起，我们俩就说话了”

**阶段三：相爱与亲密（高潮）**
- 思康喝了酒，拉着她的手说“跟了我吧”
- 秀贞描述：“北风打着窗户纸，响得吹笛儿似的。我握着他的手，暖乎乎的两个人，就不冷了。”
- 秀贞偷偷买了半空儿花生给他下酒
- 思康病了，秀贞端着粥要去送，“避点儿嫌疑，姑娘”被母亲阻拦

**阶段四：分离与怀孕**
- 思康接到家里电报，母亲病了，叫他回去
- 秀贞发现自己怀孕，但没有告诉思康（怕他惦记）
- 思康承诺“回家卖了山底下的白薯地，就到北京来娶我”
- 从此一去不返

**阶段五：生女与失女**
- 秀贞被送回海甸（娘家或亲戚家）生孩子
- 生孩子时“一点劲儿都没有，就闻着窗户外头那棵桂花树吹进来的一阵阵香气”
- 她只看了孩子一眼——“粉嘟嘟的一个小肉团子”
- 醒来后孩子不见了，家人说“扔啦！留那么一个南蛮子种儿干吗？”
- 秀贞从此被认定为“疯子”

#### 第六层：染指甲——女性情谊的象征

讲述过程中，秀贞用指甲草和“冰糖”（实为白矾）为英子染指甲。这是一个充满仪式感的亲密场景：
- 英子被当作小桂子的替身，享受“母女”间的亲密
- 染指甲是女性间的私密活动，英子因这个“标记”而进入秀贞的情感世界
- 妈妈发现后问“谁给你染的”，英子答“思康三婶”——她已认可秀贞的身份（而非“疯子”）

#### 第七层：英子的恍惚——主客观界限的模糊

本节末尾，英子的状态发生明显变化：
- 她看秀贞讲思康故事时，仿佛“躺在里屋床上的思康三叔”
- 她幻想跨院门边站着一个“红花的衫裤，一条像狗尾巴似的黄毛辫子”的女孩
- 现实中的王妈向她招手，幻影才消失
- 回家的路上，英子“脑子里好像有一幅画，慢慢越张越大，我的头也有点不舒服似的”

> 英子已经不再只是“听故事的人”，她的想象与现实的边界开始模糊。她开始“看见”小桂子，“进入”秀贞的世界。这是在为后面她“认定妞儿就是小桂子”做心理铺垫。


## 第二部分：可具体分析的点

### 分析点一：“吊死鬼”的象征意义

**核心问题：为什么林海音要在这一节的开头写“捉吊死鬼”？**

“吊死鬼”是槐树上垂下的一种虫子，英子每天捉来喂鸡，这是儿童视角中一段自然、天真的“日常”。但这个意象在文本中承担了多重功能：

| 层面 | 解读 |
|------|------|
| **现实层面** | 真实的儿童生活细节（捉虫、喂鸡），建立小说的“生活感” |
| **意象层面** | “吊死鬼”是不祥的命名——虫子在瓶中蠕动、在秀贞的故事中潜伏着死亡与失去 |
| **心理层面** | 英子捉虫时“忽然想到了妞儿，心里很不安”——不安的情绪和“吊死鬼”的形象叠合 |
| **结构层面** | 英子捉完虫放瓶子→窗户台上放瓶子→英子带妞儿夜奔时再次看到瓶子→细节的呼应 |

**教学切入点**：引导学生发现，即使是一个小小的“捉虫”场景，也包含了生活真实、心理暗示和结构呼应。这不是随意的描写，而是精心设计的“针脚”。

**可提问**：为什么英子觉得“吊死鬼装在瓶子里，胳膊常常觉得痒麻麻的”？这种“痒麻麻”的感觉，除了虫子的触感外，还可能是什么？


### 分析点二：秀贞叙事的“双重时间”

**核心问题：秀贞的叙事如何同时存在于“过去”与“现在”？**

秀贞在讲述思康的故事时，不断在“回忆”与“现实”之间切换，这种叙事方式呈现了她的心理状态：

**过去时（回忆中的美好）** ——秀贞使用完整的叙述、细节丰富、情感饱满：
> “他身穿一件灰大褂，大襟上别着一支笔。”“我握着他的手，暖乎乎的两个人，就不冷了。”

**现在时（现实中的错乱）** ——秀贞反复出现时间混乱、对着空床说话、把英子当作倾诉对象：
> “有六年多了，不，还有一个多月就回来，不，还有一个月我就生小桂子了。”

**切换机制**：秀贞的“过去时”叙事越是美好、完整，回到“现在时”时的断裂感就越强烈。英子作为听众，在两种时间中穿梭，也开始产生“分不清”的感觉。

**教学切入点**：让学生找找，哪些段落是秀贞在回忆过去（美好），哪些是她回到当下（混乱）。对比这两种语言的味道有什么不同。

**可提问**：秀贞回忆思康时，语言非常优美流畅；但一回到“现在”，她就混乱了。这说明什么？


### 分析点三：秀贞与思康的爱情——旧时代知识青年与卑微女性的结合

**核心问题：这段爱情为什么注定是悲剧？**

从秀贞的叙述中，我们可以分析这段爱情的几个结构性矛盾：

| 矛盾层面 | 具体表现 |
|---------|----------|
| **阶级差距** | 思康是大学生（“北京大学”），秀贞是看门人的女儿（不识字） |
| **地域差距** | 思康是南方人（惠安，福建沿海），秀贞是北方人 |
| **家庭阻力** | 思康母亲病重，家庭牵制；秀贞父亲不认可（“留那么一个南蛮子种儿干吗”） |
| **社会观念** | 未婚先孕是“丢人”的，秀贞被送回海甸“避嫌” |
| **经济困窘** | 思康“又薄又旧的棉被”，承诺“卖了山底下的白薯地”才能娶她 |
| **通信条件** | 思康一去六年，没有任何消息，音信隔绝 |

**教学切入点**：这段爱情不是因为“谁变心了”而破碎，而是被社会结构、阶级差异、地域隔阂、家庭压力共同碾碎的。学生由此可以理解：个人的悲剧往往不完全是“个人选择”的结果。

**可提问**：思康对秀贞是真心的吗？如果是，他为什么没能回来？你觉得他遇到了什么？


### 分析点四：秀贞叙事中的“身体记忆”

**核心问题：秀贞用哪些身体细节来“保存”她的爱情与孩子？**

| 身体细节 | 情感意义 |
|---------|----------|
| 思康的眼睛“到底有多深” | 第一眼的震撼，是一见钟情的标志 |
| “他拉起我的手，就像我这么拉你的手” | 肢体接触的情感意义，秀贞用“拉英子的手”重温当年的感觉 |
| “他的脸滚烫，贴着我的脸” | 爱情的身体记忆（酒、温暖、亲密） |
| “我握着他的手，暖乎乎的两个人” | 寒冷中互相取暖，成为爱情最深的印记 |
| 生孩子时“咬住了辫子” | 身体承受的痛苦与生命的诞生 |
| “闻着窗户外头那棵桂花树吹进来的一阵阵香气” | 身体感官与记忆的联结（嗅觉→情感） |
| 脖子后的青记 | 身体标记作为身份的唯一证据 |

**教学切入点**：引导学生注意，秀贞的故事不是“讲”出来的，而是用“身体”记住的——手的温度、脸的热度、桂花的香气、咬辫子的疼痛。这些感官记忆比语言更深刻、更真实。

**可提问**：秀贞记得最清楚的细节，都是和身体感受有关的。你从哪些地方能感受到她真的爱过思康？


### 分析点五：“避嫌”——旧社会对女性的规训

**核心问题：母亲对秀贞说“避点儿嫌疑，姑娘”，这句话意味着什么？**

当秀贞端着粥要给病中的思康送去时，母亲拦住了她，说了这句话。这是很简短的一句话，但包含了旧时代对女性的一整套规范：

**表层含义**：你是未婚姑娘，不能单独出入单身男子的房间。

**深层含义**：
- 女性的身体和行动是受监控的
- “嫌疑”意味着即使你没有做错事，也可能“被认为”做错了
- 女性要为“名声”负责，而男性不需要
- 这句话暗示了秀贞后来怀孕后“说不出口”的原因——她已经被训练得不敢谈论自己的身体

**讽刺的是**：母亲拦住了秀贞送粥（守规矩），却没有能拦住秀贞怀孕（爱情的发生）。规矩管住了“表面行为”，却管不住真实的情感与欲望。

**教学切入点**：引导学生思考，秀贞后来“说不出口”自己怀孕了，和这句“避点儿嫌疑”有什么关系。

**可提问**：如果你是秀贞，母亲对你说“避点儿嫌疑”，你会怎么想？这句话是否影响了秀贞后来“不告诉思康我有了”的决定？


### 分析点六：“缘分”——秀贞对自己命运的解释

**核心问题：秀贞如何理解自己与思康的相遇？**

秀贞在叙述中反复说到一个词：“缘分”。

> “看他那模样儿，两只眼儿到底有多深！你还没看清楚他，他就把你看穿了……我心里一跳，迈门坎儿差点摔出去！……回到屋里来，我吃饭睡觉，眼前都摆着他的两只那么样看人的眼睛。这就是缘分，会馆一年到头，来来往往的大学生多了，怎么我就一一我就，……”

**“缘分”在秀贞的理解中具有以下功能：**

| 功能 | 说明 |
|------|------|
| **解释不可解释之事** | 为什么来来往往的大学生那么多，偏偏是思康？ |
| **赋予命运以意义** | 这不是偶然，是“命里注定” |
| **为爱情提供合法性** | 是“缘分”让我们相爱，不是我“不检点” |
| **维持希望** | 既然是缘分，他就应该回来——缘分不该只走到半路 |

**更深一层**：秀贞用“缘分”来解释自己的命运，她并没有意识到这段爱情之所以发生，是源于她在男性主导的社会结构中处于弱势——她没有被当作“平等的个体”来爱，而是在一种“被看穿”“被选中”的关系中确立了自己的价值。但这并不意味着她的情感不真实。“缘分”是她给自己爱情故事赋予意义的唯一方式。

**教学切入点**：让学生讨论——“缘分”是真的存在，还是人们在无法解释命运时的一种安慰？

**可提问**：秀贞说“这就是缘分”，你同意吗？如果你是她，你会怎么理解这件事？


### 分析点七：王妈的“打断”——日常对苦难的压制

**核心问题：为什么秀贞每次讲到关键处，都会被母亲打断？**

本节中，秀贞的叙述多次被母亲王妈打断：
- 秀贞正讲到思康如何来会馆、如何住下，王妈打断说“小英子，该回去了”
- 王妈说“你怎么那么爱听她那颠三倒四的废话”

| 王妈的行为 | 表层意图 | 深层含义 |
|-----------|---------|----------|
| 打断秀贞说话 | 怕她“胡说”吓到英子 | 不让秀贞的“真相”被听到 |
| 禁止英子听 | “别听她的废话” | 维护家庭表面的“正常” |
| 催促英子离开 | 天黑了，该回家了 | 切断英子与秀贞的联结 |

**王妈的角色分析**：
- 她是秀贞的母亲，也是参与了“把孩子送走”的人
- 她不希望秀贞的故事被重复讲述——因为故事里也包含了她自己的“罪责”
- 她通过“打断”来维持日常秩序，但这种“打断”恰恰让秀贞的悲剧永远无法被正视

**教学切入点**：日常生活中，有多少苦难是被“好了别说了”“别提那些事了”这类话压下去的？“打断”是一种无形的暴力。

**可提问**：王妈不让秀贞把话说完，是真的怕吓到英子，还是不想让那些事被提起？你怎么看？


### 分析点八：英子的“恍惚感”——儿童心理的真实呈现

**核心问题：英子在这一节中出现了哪些“恍惚”的状态？这说明了什么？**

本节中，英子的主观体验出现了明显变化，她的内心世界与外部现实的界限开始模糊：

**表现一：想象与现实的混淆**
> “在我的幻想中，跨院门边，应当站着一个女孩子，红花的衫裤，一条像狗尾巴似的黄毛辫子，大大的眼睛，一排小帘子似的长睫毛，一闪一闪的，在向我招手呢！”——英子想象的小桂子形象，混合了秀贞描述的“小桂子”和英子认识的“妞儿”。

**表现二：人物的叠合**
> “再睁开眼，她变成秀贞的脸了”——英子看妞儿时，恍惚间看到的是秀贞。说明在英子的潜意识中，妞儿和秀贞已经是“同一个人”了。

**表现三：身体反应的混乱**
> “我头有点昏，好像要倒下来”——英子的身体在承受她心理上无法完全消化的信息。

**心理分析**：
- 英子只有六岁，她接收了太多成人世界的情感信息（秀贞的悲伤、妞儿的秘密）
- 她的理性无法完全“处理”这些信息，于是表现为恍惚、头晕、分不清
- 这种恍惚不是“病”，而是孩子面对沉重现实时的正常心理反应

**教学切入点**：帮助学生理解，这种“恍惚”不是林海音写得“不清楚”，恰恰是她在准确呈现一个六岁孩子的心理状态。

**可提问**：英子为什么会在看妞儿时，恍惚间把她看成秀贞？你觉得这说明了什么？


### 分析点九：本节在全书结构中的位置

**核心问题：第三节在全书的情节推进中发挥了什么作用？**

| 功能 | 具体说明 |
|------|----------|
| **情感铺垫** | 秀贞与思康的爱情被完整讲述，读者对秀贞的同情达到高峰 |
| **线索推进** | 妞儿的身世进一步明确（齐化门、被捡来、非亲生） |
| **英子的转变** | 英子从“旁观者”变为“卷入者”，她的恍惚为后面“带妞儿夜奔”做心理铺垫 |
| **悬念加强** | 读者和英子都已经“快要猜到”妞儿就是小桂子，但还没有最终确认 |
| **对比强化** | 秀贞回忆中的美好爱情 vs 现实中的孤独疯癫，悲喜交织，情感张力最大 |

**教学切入点**：本节是全篇的“情感高潮”所在——秀贞的爱情故事讲完了，读者已经“完全理解”了她。剩下的就是等待那个“认出”的时刻。

**可提问**：读完第三节，你觉得秀贞最让你心痛的，是她失去爱人，还是失去孩子？还是两者加在一起？


## 第三部分：教学建议

### 重点教学段落

建议在课堂上重点精读以下段落：

1. **秀贞讲述思康初到会馆**（“这是这时节他来的……我一走神，迈门槛差点摔出去！”）——观察秀贞如何用身体记忆讲述爱情。
2. **秀贞讲述相爱的场景**（“他喝了点儿酒，我也迷糊了……暖乎乎的两个人，就不冷了。”）——体会温暖中的悲凉。
3. **秀贞讲述生小桂子**（“小桂子生下来，真不容易……”）——感受生命诞生与失去交织的痛。
4. **英子的恍惚**（“我头有点昏……一个脸，被我看成两个脸”）——分析儿童心理的真实书写。

### 课堂活动建议

1. **“秀贞的回忆与现实的对照表”** ：让学生从本节中摘录秀贞在“回忆过去”和“面对现在”时的不同话语，比较两种状态下的语言特点。

2. **角色扮演“秀贞讲故事的场景”** ：请两位学生分饰秀贞和英子，在朗读中体会秀贞叙述时的情绪变化。

3. **讨论：“缘分”是什么？** ——从秀贞的“这就是缘分”出发，讨论学生对“命运”“缘分”的理解。

4. **“英子日记”写作**：从英子的视角，写一篇她回家后的日记，记录今天在秀贞那里听到的一切和她的感受。

### 与第一、二节的关联

| 第一节 | 第二节 | 第三节 |
|--------|--------|--------|
| 秀贞出场，被称作“疯子” | 秀贞哭小桂子 | 秀贞完整讲述爱情故事 |
| 读者初见“疯子”的外表 | 读者开始了解“疯子”的内心 | 读者完全理解“疯子”的遭遇 |
| 伏笔开始埋下（齐化门、青记） | 秀贞与英子建立亲密关系 | 所有伏笔汇聚，真相即将揭晓 |

### 核心教学价值

第三节的核心价值在于：**它让读者从“同情一个疯子”转变为“理解一个女人”** 。秀贞的爱情故事被完整地、细腻地、充满感官细节地呈现出来，读者被邀请进入她的内心世界，而不是隔着“疯子”的标签去评判她。这是《城南旧事》在情感教育上最重要的意义之一。

# 《城南旧事·惠安馆》阅读卡（第三节）参考答案

> **说明**：阅读卡中包含大量开放性问题，不同学生可能有不同理解。以下答案仅供参考，并非“唯一标准答案”。教师可根据学生的实际回答灵活评判，鼓励合理、有文本依据的个人见解。

## 一、阅读前·想一想

**1. 你觉得思康是个怎样的人？**

- 开放性问题，鼓励学生根据前两节的间接信息做出推断。
    
- 参考方向：神秘的/不负责任的/被迫离开的/真心爱秀贞的/软弱的……
    
- 只要学生能从前文找出依据即可（如：秀贞说他要回来娶她→说明他承诺过；但他六年没回来→说明他失约了）。
    

**2. 如果你等一个人等了六年，你会放弃吗？**

- 开放性问题，鼓励学生真实表达。
    
- 参考示例：可能会放弃，因为六年太长了/不会放弃，因为答应了就要等下去/不确定，要看具体原因。
    
- 教师引导：这个问题没有标准答案，重点是想让学生体会秀贞等待六年的不易。
    

**3. 秀贞的父母为什么把孩子偷偷送走？**

- 在旧社会，未婚生子是“丢人”的事。
    
- 他们可能认为这是“为秀贞好”——让她可以“重新开始”。
    
- 他们承受着来自邻居、亲戚和社会舆论的压力。
    
- “留那么一个南蛮子种儿干吗”说明他们不接受思康（外地人、穷学生）。

## 三、阅读后·想一想

### ◎ 关于秀贞和思康的爱情

**1. 秀贞是怎么喜欢上思康的？**

> “看他那模样儿，两只眼儿到底有多深！你还没看清楚他，他就把你看穿了。……回到屋里来，我吃饭睡觉，眼前都摆着他的两只那么样看人的眼睛。”

秀贞被思康的眼神“看穿了”。她觉得“这就是缘分”——来来往往的大学生那么多，偏偏只有思康让她心动。

**2. 思康说“跟了我吧”的时候，秀贞为什么觉得“暖和”？**

当时是冬天，天气很冷，思康喝了酒，脸滚烫，秀贞握着他的手，“暖乎乎的两个人”。这里的“暖”既是身体的感觉（互相取暖），也是心里的感觉（被爱、被需要）。秀贞用身体感受来记忆爱情，这比单纯的语言更有力量。

**3. 思康离开时承诺了什么？**

> “回家卖了山底下的白薯地，就到北京来娶我。”

思康承诺会回来娶秀贞。

**4. 秀贞为什么没有告诉思康自己怀孕了？**

秀贞说：“我当时就没告诉他我有了，反正他去个把月就回来。……我要是告诉他我有了，不也让他惦记着！”她不想让思康担心，而且她相信思康很快会回来娶她，到时再说也不迟。

**5. 你觉得思康还会回来吗？为什么？**

- 参考观点一：**不会回来了**。六年没有任何音讯，如果真心想回来，早该回来了。可能被家里扣住了、结婚了，甚至可能已经不在人世。
    
- 参考观点二：**也许有苦衷**。秀贞说“思康准是让他妈给扣住了”，在那个年代，父母之命无法违抗。
    
- 核心理解：无论思康回不回来，秀贞的精神已经永远停留在他离开的那一天了。这是她“疯”的本质。
    

### ◎ 关于秀贞的母亲（王妈）

**6. 秀贞要给思康送粥时，妈妈说了什么？**

> “避点儿嫌疑，姑娘，懂得不懂得？”

**7. “避嫌”是什么意思？**

“避嫌”就是避开可能引起别人怀疑或误会的事情。在当时的社会，一个未婚姑娘单独出入单身男子的房间，即使只是送粥，也会被认为“有嫌疑”——被人议论、被人说闲话。所以母亲要她“避嫌”。

这句话显示了旧社会对女性的严格管束：女性要时刻注意自己的“名声”，而男性不需要。

**8. 王妈为什么要打断秀贞讲故事？**

- 表层原因：怕秀贞“胡说”吓到英子。
    
- 深层原因：
    
    - 她不想让秀贞的“家丑”被外人（尤其是小孩子）知道。
        
    - 她自己参与了“把孩子送走”这件事，秀贞每次讲述，都在提醒她自己的“罪责”。
        
    - “打断”是维持家庭表面正常的一种方式——不说就等于没有发生。
        
- 王妈的角色是复杂的：她既是秀贞的母亲（可能也心疼女儿），也是这个悲剧的参与者。
    

### ◎ 关于英子

**9. 英子的幻觉中，跨院门口的女孩是什么样子的？**

> “红花的衫裤，一条像狗尾巴似的黄毛辫子，大大的眼睛，一排小帘子似的长睫毛，一闪一闪的，在向我招手呢！”

这个形象混合了秀贞描述的“小桂子”和英子认识的“妞儿”：

- “红花的衫裤”→ 秀贞给小桂子做的衣服
    
- “像狗尾巴似的黄毛辫子”→ 妞儿的辫子
    
- “大大的眼睛，一排小帘子似的长睫毛”→ 妞儿的眼睛
    

**10. 英子为什么会出现这种幻觉？**

英子在潜意识中已经“感觉”到妞儿就是小桂子。她的理性还没有完全想明白，但她的情感和直觉已经先到了。她接收了太多信息（秀贞的悲伤、妞儿的身世、青记的线索），她的大脑在努力把这些碎片拼在一起。这种“恍惚”是一个六岁孩子在面对沉重真相时的正常反应。

### ◎ 深入思考

**11. 你觉得秀贞最让你心疼的是什么？**

- 开放性问题，鼓励学生表达真实感受。
    
- 参考方向：
    
    - “失去孩子”最心疼——因为孩子是她唯一的希望和延续。
        
    - “被人叫疯子”最心疼——她不是疯了，只是太痛苦了。
        
    - “失去爱人又失去孩子”叠加在一起——两重失去，任何一个都难以承受。
        
    - “没有人真正听她说话”——只有英子愿意听。
        

**12. 你相信缘分吗？**

- 开放性问题，不设标准答案。
    
- 参考方向：
    
    - 相信缘分：世间很多相遇无法用常理解释，冥冥之中有安排。
        
    - 不太相信缘分：所谓的“缘分”很多时候是巧合，或者是人们给不幸找的安慰。
        
    - 对秀贞来说，“缘分”是她给自己爱情故事赋予意义的唯一方式——如果没有缘分，她的等待就毫无意义。所以她必须相信。
        

**13. 为什么秀贞记得的都是“身体的感觉”？**

秀贞不识字，她没有用“文字”来记录爱情的方式。她用的全是感官记忆：

- **触觉**：“他拉起我的手”“暖乎乎的两个人”
    
- **视觉**：“两只眼儿到底有多深”
    
- **嗅觉**：“桂花的香气”
    
- **听觉**：“北风打着窗户纸”“哭声好大呀”
    
- **味觉**：“半空儿花生”
    

这些感官记忆比文字更原始、更深刻、更难以抹去。当一个人无法用文字表达自己的经历时，她的身体就替她记住了所有的事情。这也是为什么秀贞的叙述如此动人——它是“身体在说话”。

## 四、阅读挑战·选做题

### □ 挑战一：秀贞的独白（参考示例）

思康，你走了多久了？我想你，每一天都在想你。

今天有个小姑娘来听我说话，她叫英子，眼睛亮亮的。我给她讲了你的事，讲了我们在跨院的那些日子。你记得吗？你拉着我的手，说“跟了我吧”，那时候外面刮着北风，你的手好暖和……

我肚子里有了你的孩子，但我没有告诉你。我想等你回来再说，等你卖了白薯地回来娶我，给你一个惊喜。可是你怎么不回来呢？

小桂子生下来了，她好小，好软，闻着桂花的香。可我一醒来，她就没了。他们把她送走了……我连她长什么样都没看清，只记得她脖子后面有一块青记，像阎王爷用手指头戳的。

我到处找她，但他们说我疯了。思康，我不疯，我只是想你们了。你们什么时候回来？

### □ 挑战二：给秀贞的信（参考示例）

秀贞：

听完你的故事，我心里很难过。

你记得思康说的每一句话，记得他穿什么衣服、生什么病，记得小桂子出生时桂花的香味。你不是疯子，你只是太想念他们了。

我认识一个叫妞儿的女孩，她就住在井窝子旁边。她的眼睛和你一样，笑的时候也有泪坑儿。她说她不是亲生的，她被捡来的时候住在齐化门那边。你说小桂子也被送到齐化门了……

我不敢确定，但我的心里一直觉得有什么东西连在一起。你放心，我会帮你看着她的。

你要好好的。如果思康回来了，如果小桂子找到了，那该多好啊！

### □ 挑战四：词语品味（参考示例）

**句子一：**

> “北风打着窗户纸，响得吹笛儿似的。我握着他的手，暖乎乎的两个人，就不冷了。”

**我的感受：** 外面是寒冷的冬天，但屋里两个人的手是暖的。秀贞用“暖和”这个最简单的词，写出了爱情最动人的时刻——不是轰轰烈烈的誓言，而是两个人互相取暖的安静瞬间。

**句子二：**

> “小桂子生下来，真不容易，我一点劲儿都没有，就闻着窗户外头那棵桂花树吹进来的一阵阵香气。”

**我的感受：** 生孩子是最痛苦、最累的时候，但秀贞记住的是一阵花香。这说明对她来说，小桂子的出生是美好的、带着香气的记忆，哪怕之后一切都破碎了，这个瞬间的美好是偷不走的。
