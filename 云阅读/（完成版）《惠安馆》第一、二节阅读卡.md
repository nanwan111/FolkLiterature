## 三、阅读后·想一想

认真读完《惠安馆》第一、二节后，请思考下面的问题。

### ◎ 问题一：关于“疯子”

1. 大人们为什么叫秀贞“疯子”？请列出至少两个原因。  
   （1）经常发呆，念叨自己孩子的名字。  
   （2）大家都这么说。

2. 英子眼中的秀贞是什么样的？和大人们有什么不同？

| 大人眼中的秀贞 | 英子眼中的秀贞        |
| ------- | -------------- |
| 危险、要躲开  | 一个梳辫子的大姑娘      |
| 说话颠三倒四  | 说的话有道理，只是太想孩子了 |
| 疯子、不正常  | 可怜、可爱、像普通人一样笑  |
| 不能跟她说话  | 想跟她说话、想跟她玩     |

3. 你觉得秀贞是“疯子”吗？用一句话写下你的看法：  
   不是，她头脑其实很清醒，只是很思念自己的女儿和爱人，思念过度而导致的行为举止的异常。

### ◎ 问题二：关于英子

4. 英子为什么不怕秀贞，反而想走过去和她说话？  
   孩子没有大人的偏见，不会先入为主地认为“疯子是可怕的”。秀贞对英子笑、招手，英子感受到的是善意。

5. 英子在大人眼里是个怎样的孩子？从文中找出一个细节来证明。  
   **好奇**：什么事都要问，妈妈说“总是问，总是问，你这孩子”。
   **胆大**：敢走近秀贞、敢偷偷溜进惠安馆。

### ◎ 问题三：关于秀贞和妞儿

6. 秀贞一直在找她的孩子。你从哪些地方能感受到她对小桂子的思念？（至少写两处）  
   （1）她反复回忆小桂子出生时的情景——桂花香、哭声、青记，每个细节都记得清清楚楚。
   （2）她在跨院里哭着喊“小桂子，小桂子，你怎么不要妈了呢”——声音“多么委屈，多么可怜”。

8. 妞儿告诉英子的秘密是什么？这个秘密和秀贞的故事有什么相似的地方？  
   妞儿的秘密是：“我不是我妈生的，我爸爸也不是亲的。”她是在齐化门被捡来的。

### ◎ 问题四：故事里藏着线索
